# CRM Management System

Sistema CRM desarrollado para la gestión de clientes, contactos, oportunidades y tareas empresariales.

## 🚀 Características

* Gestión de clientes
* Gestión de contactos
* Seguimiento de oportunidades de venta
* Gestión de tareas y actividades
* Dashboard con métricas
* Sistema de autenticación y autorización
* API REST
* Base de datos relacional
* Diseño responsive

## ⚙️ Instalación

### Clonar repositorio

```bash
git clone https://github.com/tuusuario/crm-project.git
```

### Acceder al proyecto

```bash
cd crm-project
```

### Levantar contenedores

```bash
docker compose up -d
```

### Acceder a la aplicación

```text
http://localhost
```
